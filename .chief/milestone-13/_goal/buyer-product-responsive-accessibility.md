# Buyer Product Responsive Accessibility

## Goal

Verify the improved buyer product UI is usable across mobile and desktop and meets basic accessibility expectations.

## In Scope

- Responsive verification for product detail and listing/search card surfaces.
- Keyboard focus states for gallery controls, variant controls, quantity controls, quick add, add-to-cart, and buy-now.
- Accessible labels for icon buttons and product actions.
- Browser screenshot verification after UI implementation.
- Tests for loading, empty, error, and interaction states.

## Out of Scope

- Full site-wide accessibility audit.
- Checkout/cart accessibility work beyond product action entry points.
- Design system rewrite.

## Constraints

- Text must not overflow or overlap in mobile or desktop layouts.
- Interactive controls must have stable dimensions.
- UI should remain buyer marketplace focused and not use landing-page hero patterns.
