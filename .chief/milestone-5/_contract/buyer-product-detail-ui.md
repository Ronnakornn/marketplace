# Contract: Buyer Product Detail UI

## Gallery

Required behavior:

- selected image preview
- thumbnails
- video slot/tab when product video exists
- empty media fallback

## Variant Selection

Required behavior:

- option-based picker for up to two axes
- disabled out-of-stock values
- selected variant summary
- price updates from selected variant
- stock updates from selected variant

Rules:

- Buyer cannot add to cart or buy now without selecting a required variant.
- Buyer cannot select quantity above available stock.
- Out-of-stock product state disables purchase CTAs but keeps product info readable.

## Transaction Controls

Required behavior:

- quantity stepper
- Add to Cart
- Buy Now
- Chat Seller
- Favorite
- Follow Shop
- sticky bottom CTA on mobile

## Product Information

Required sections:

- title, price, rating, sold count, stock state
- shop card
- shipping/protection information
- category specs table
- highlights
- description
- reviews preview
- related products
