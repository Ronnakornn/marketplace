# Goal: Product UX/UI Scope

## Outcome

Product workflows are usable end-to-end across seller, admin, and buyer surfaces after milestone 4 product contracts are implemented.

## Scope

- Build UX/UI for product management and product purchase readiness.
- Depend on milestone 4 product, SKU, inventory, media, category, and moderation contracts.
- Keep this milestone focused on UI composition, client behavior, frontend state, and visual verification.
- Do not introduce new core domain rules unless milestone 4 contracts are found insufficient.
- Do not redesign homepage or search discovery in this milestone.

## Success Criteria

- Seller can manage a product without direct API calls.
- Admin can moderate submitted products without direct API calls.
- Buyer can select a valid SKU variant and quantity before cart or buy actions.
- UI uses existing app shells, shadcn/ui, Tailwind, Eden Treaty, and React Query.
