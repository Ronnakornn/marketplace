# Goal: Product Media Manager UX

## Outcome

Sellers can upload, review, order, and attach product media required for publish readiness.

## Scope

- Use the existing upload workflow from milestone 4.
- Support drag/drop or file picker upload.
- Show pending, progress, completed, and error states.
- Support image reorder, primary image selection, alt text edit, and removal.
- Support one product video slot with preview.
- Do not implement image cropper, background remover, or per-variant media mapping.

## Success Criteria

- Media readiness warnings are visible before submit review.
- Exactly one primary image can be selected.
- Upload failures do not corrupt existing media state.
- Video preview handles empty, loading, success, and unsupported states.
