# Product Detail Verification

## Goal

Verify product detail UX/UI changes with automated tests and browser evidence.

## In Scope

- Focused tests for product detail variant, stock, quantity, add-to-cart, buy-now, guest, and non-buyer states.
- Typecheck and full test run before completion.
- Browser evidence for desktop product detail.
- Browser evidence for mobile product detail.
- Browser evidence for logged-in buyer add-to-cart or buy-now handoff.

## Out of Scope

- Cross-browser certification.
- Load testing.
- Production payment provider validation.

## Constraints

- Save evidence or notes under `.chief/milestone-17/_report/`.
- Document local seed-data limitations if browser cannot reach a specific state safely.
