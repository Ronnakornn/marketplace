# Goal: Search and Listing UX

## Outcome

Buyers can find products through keyword, category, filter, and sort flows on mobile and desktop.

## Scope

- Keyword search.
- Category breadcrumb and category tree filtering.
- Brand filter.
- Price range filter.
- Rating filter.
- Category specs and attribute filters.
- In-stock filter.
- Shipping or promotion badge filters where data exists.
- Sort by relevance, newest, price low/high, top sales, and rating.
- Mobile filter sheet and desktop sidebar.
- Recent searches and popular searches.
- Useful empty states with suggested categories or keywords.
- Do not implement typo-tolerant search, semantic search, or advanced personalized ranking.

## Success Criteria

- Filter state is visible, removable, and reflected in URL query state.
- Mobile and desktop filtering are functionally equivalent.
- Empty states guide buyers to useful next actions.
- Search and category listing remain performant with pagination or incremental loading.
