# Buyer support and repeat purchase

Buyers can report order problems, exchange messages, appeal a rejected return and see an administrator's decision. Sellers can respond only to tickets scoped to their shops. Administrators can review cases and keep private notes.

Buyers can put an earlier order's available variants in the cart at current prices. Historical order snapshots remain immutable. Repeated requests do not multiply quantities. Unavailable variants produce visible per-item outcomes.

Both features include Thai and English UI and meaningful ownership, transaction and browser verification.
