# Product Listing Search Mobile UX

## Goal

Improve buyer Product Listing/Search UX with a mobile-first search, filter, and sort flow.

## In Scope

- Buyer product listing/search surfaces under the existing product frontend feature.
- Mobile-first filter and sort entry points.
- Search result readability, scanability, and buyer decision flow.
- Responsive behavior that remains usable on desktop.

## Out of Scope

- Backend API changes.
- Search ranking, filter semantics, or sort behavior changes.
- Product detail page redesign.
- Checkout, cart, payment, order, inventory, and seller behavior.

## Constraints

- Use existing product query/data contracts.
- Preserve same-origin `/api/*` frontend behavior.
- Keep buyer-facing UI consistent with existing marketplace theme.
- Do not duplicate backend response types on the frontend.
