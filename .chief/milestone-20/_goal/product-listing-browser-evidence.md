# Product Listing Browser Evidence

## Goal

Capture browser evidence for the buyer Product Listing/Search UX after the mobile-first polish.

## In Scope

- Mobile Product Listing/Search screenshot.
- Desktop Product Listing/Search screenshot.
- Evidence for filter/sort sheet or active filter chips where feasible.
- Notes saved under `.chief/milestone-20/_report/`.

## Out of Scope

- Cross-browser certification.
- Backend load or search relevance testing.
- Checkout or product detail browser regression unless listing changes directly affect navigation.

## Constraints

- Browser verification must use frontend same-origin routes.
- If dev server, seed data, or existing environment failures block evidence, document the exact blocker.
- Stop local dev processes started for evidence after verification.
