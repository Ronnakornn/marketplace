# รูปสินค้าตัวอย่าง

SVG ในโฟลเดอร์นี้เป็นภาพวาดสินค้าตัวอย่างที่สร้างตามชนิดสินค้าสำหรับ demo/UAT แต่ละสินค้ามีสองมุมมอง รูปภาพถ่ายที่นำมาใช้ร่วมอยู่ใน public/uat และมีที่มากับ license บันทึกไว้ที่นั่น

Mapping อยู่ใน scripts/product-image-catalog.json รวม gallery ของสินค้า UAT ทั้งหมด สินค้าทดสอบอื่นใช้ชุดตามหมวดหมู่ คำสั่ง bun run db:seed:product-images เติมและตรวจรูปในฐาน local โดยรักษารูปที่ผู้ทดสอบอัปโหลดเอง
