# รูปสำหรับ UAT

ชุดนี้มีรูปสินค้า 52 รูปสำหรับ 20 สินค้า โลโก้ร้าน 4 รูป ปกร้าน 4 รูป โลโก้แบรนด์ 4 รูป และรูปแนบรีวิว 2 รูป

รูปสินค้ามาจาก [DummyJSON products](https://dummyjson.com/docs/products) และเก็บไฟล์ WebP ต้นฉบับไว้ในโปรเจกต์ ชื่อสินค้าใน `scripts/uat/catalog.json` ตรงกับรูปต้นทาง ราคา สต็อก และคำอธิบายภาษาไทยเป็นข้อมูลที่กำหนดสำหรับ UAT

`assets.json` บันทึก URL ต้นทาง ขนาด และ SHA-256 ของแต่ละไฟล์ โลโก้และปกร้านเป็น SVG ที่เขียนสำหรับร้าน UAT โดยเฉพาะ รูปรีวิวเป็นสำเนาของรูปสินค้าสำหรับทดสอบการแนบไฟล์ และไม่ใช่หลักฐานการซื้อของลูกค้าจริง

ตรวจไฟล์โดยไม่เชื่อมต่อเครือข่ายด้วยคำสั่งนี้:

```sh
bun run uat:assets --check
```

กู้รูปสินค้าที่หายจาก URL ต้นทางด้วยคำสั่งนี้:

```sh
bun run uat:assets
```

คำสั่งจะตรวจ checksum ก่อนบันทึกไฟล์ หากต้นทางเปลี่ยนรูป คำสั่งจะหยุด รูป SVG ให้กู้จาก Git
